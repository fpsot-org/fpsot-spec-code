= HTML and CSS
include::_fpsot-terms.adoc[]

This page covers templates that render {abbr-html-first}, and style sheets.
The accessibility specification sets what the pages must offer people, from ACC-001 on.
The style specification sets the design tokens and the themes, from STY-001 on.
This page adds the mechanical rules.

== Rules

[[COD-650]]
*COD-650.* The {abbr-ci-first} MUST check rendered pages with the Nu HTML Checker, and fail on an error.
Check: the link:https://validator.github.io/validator/[Nu HTML Checker] in {abbr-ci}.

A template is not yet {abbr-html}, so the check reads the pages that the application renders in its tests.

[[COD-651]]
*COD-651.* Templates MUST NOT hold inline scripts, `style` attributes or attributes that handle events.
Scripts MUST work under a content security policy without `'unsafe-inline'` or `'unsafe-eval'`.
A script library that compiles expressions at run time MUST then use its build for strict policies.
Check: a test that loads each page under that policy, and review.

The link:https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Security-Policy/script-src[MDN page on script-src] explains how these keywords weaken the policy.

[[COD-652]]
*COD-652.* A Qute template MUST NOT output data that a person supplied without escaping.
It MUST NOT apply `raw` or `safe` to such data.
Check: a {abbr-ci} search for `raw` and `safe` in templates, and review of each hit.

The link:https://quarkus.io/guides/qute-reference[Qute reference guide] escapes output by default in {abbr-html} templates.

[[COD-653]]
*COD-653.* Style sheets MUST pass stylelint with `stylelint-config-standard`.
They MUST take colors, spacing and type from the custom properties of the design system, under STY-001.
Check: link:https://stylelint.io/[stylelint] in {abbr-ci}, with `color-no-hex` and `color-named` for raw colors.
The plugin link:https://github.com/AndyOGo/stylelint-declaration-strict-value[stylelint-declaration-strict-value] checks spacing and type, and review covers the rest.

[[COD-654]]
*COD-654.* Style sheets SHOULD order their layers with `@layer`, in the manner of CUBE CSS.
Blocks that {abbr-fpsot-first} writes SHOULD take class names in the manner of BEM.
A project SHOULD use the components and tokens of PatternFly before it writes its own.
Check: review.

link:https://cube.fyi/[CUBE CSS] and link:https://getbem.com/[BEM] fit together.
CUBE orders the layers, and BEM names the blocks inside them.
