== Rules

[[COD-850]]
*COD-850.* YAML files MUST pass yamllint with a committed configuration.
The configuration MUST allow only `true` and `false` as truth values, and MUST treat a repeated key as an error.
Check: link:https://yamllint.readthedocs.io/en/stable/[yamllint] in {abbr-ci-first}, with its rules `truthy` and `key-duplicates`.

YAML 1.1 reads words such as `yes` and `on` as truth values, which surprises readers and tools.
The file `examples/.yamllint.yaml` shows a configuration.

[[COD-851]]
*COD-851.* The {abbr-ci} MUST check each configuration file that has a published schema against it.
Check: link:https://check-jsonschema.readthedocs.io/en/stable/[check-jsonschema] in {abbr-ci}.

check-jsonschema includes the schemas of GitHub workflows and of Dependabot, among others.

[[COD-852]]
*COD-852.* Each configuration format that {abbr-fpsot-first} defines MUST ship a {abbr-json} Schema in the link:https://json-schema.org/draft/2020-12[2020-12 draft].
Check: review.

The {abbr-fpsot} interface rules use the same draft, under API-023.
