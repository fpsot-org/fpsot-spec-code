== Rules

[[COD-750]]
*COD-750.* The build file of an image MUST have the name `Containerfile`.
A Quarkus project MAY keep the generated `src/main/docker/Dockerfile.jvm` and `Dockerfile.native` files instead.
It MUST pass hadolint at the threshold `warning`, with a committed configuration.
Check: link:https://github.com/hadolint/hadolint[hadolint] in {abbr-ci-first}.

hadolint checks that each base image names a tag, and runs ShellCheck on each `RUN` line.
The file `examples/.hadolint.yaml` shows a configuration.

[[COD-751]]
*COD-751.* Each `FROM` line MUST carry the digest that SEC-031 asks for, with the tag in a comment after it.
The build MUST use stages, so that build tools stay out of the final image.
The last `USER` line MUST name a numeric user other than 0.
Check: a {abbr-ci} search for `@sha256:` on each `FROM` line.
The same search checks for a number other than 0 on the last `USER` line.
The rule DL3002 of hadolint only checks that this user is not root.

[[COD-752]]
*COD-752.* Each image MUST carry the labels `org.opencontainers.image.source`, `org.opencontainers.image.revision`, `org.opencontainers.image.version` and `org.opencontainers.image.licenses`.
Check: a test of the built image, such as with `podman inspect`, and review.

The link:https://github.com/opencontainers/image-spec/blob/main/annotations.md[OCI image annotations] define these keys.

[[COD-753]]
*COD-753.* Each image MUST build without root, with Podman or Buildah.
A secret that the build needs MUST come from a secret mount, never from a layer, under SEC-020.
Check: the {abbr-ci} job builds without root, and review.

The link:https://docs.podman.io/en/latest/markdown/podman-build.1.html[reference page of podman build] describes how to mount a secret.

[[COD-754]]
*COD-754.* A build SHOULD set `--source-date-epoch` to the time of the last {term-commit}, and SHOULD use `--rewrite-timestamp`.
It SHOULD pin package repositories to a snapshot.
Check: the release workflow rebuilds and compares, under COD-022.

link:https://buildah.io/releases/2025/07/21/Buildah-version-v1.41.0.html[Buildah 1.41] added these options, and Podman passes them on.
Logs of package managers can still hold timestamps, which is why this rule stays a SHOULD.
